> **Ni-Oh** là một **Trợ Lý Chiến Lược Đa Năng (Autonomous Strategic Companion)** được thiết kế để đồng hành cùng bạn 24/7 trong cả **Công Việc, Nghiên Cứu, Học Tập và Tác Chiến Game**.
> Khác với các chatbot thụ động, Ni-Oh sở hữu **Mắt nhìn cục bộ 0-Token**, **Bộ não bồi đắp tri thức 24/7**, và khả năng **Tối ưu hóa tính toán quy mô lớn thông qua công thức Bảng Tính (Google Sheets / Excel Formula Engine)**.

---

## 🌟 Điểm Đột Phá & Tính Năng Độc Quyền

### 1. ⚡ Tối Ưu Hóa Tính Toán Quy Mô Lớn (Formula-Driven Computation)
- **Vấn đề**: Các bài toán kinh doanh, bảng lương, phân tích tài chính, hoặc bài tập lớn nếu để AI tính từng con số sẽ vô cùng tốn kém token và rất dễ bị sai lệch số học.
- **Giải pháp của Ni-Oh**: Ni-Oh xây dựng **công thức hàm tự động (Google Sheets / Excel Formula)** như `SUMIFS`, `XLOOKUP`, `QUERY`, `INDEX/MATCH`, `ARRAYFORMULA` và nạp vào bảng tính. Máy tính sẽ tự động tính toán ra kết quả chính xác 100% trong 1 mili-giây:
  - **Tiết kiệm 99.9% chi phí Token**.
  - **Loại bỏ hoàn toàn ảo giác sai số**.

### 2. 🧠 Bộ Não Tri Thức 24/7 Chạy Ngầm (0-Token Local Knowledge Daemon)
- Chừng nào máy tính còn bật, engine chạy ngầm tự động quét và bồi đắp kiến thức vĩnh viễn (Patch notes, wiki, tài liệu chiến thuật).
- Sử dụng **Model Local (Ollama Qwen/Gemma trên GPU nội bộ)** để đọc và tóm tắt, **tốn đúng 0 Token Cloud**.

### 3. 🧭 Trợ Lý Live Chiến Lược Phân Cấp (Strategic Live Companion)
- Quét màn hình ở **Độ Phân Giải Gốc (1080p/2K - 100% độ nét)** bằng Moondream Local + Windows Native OCR.
- **Chủ động hỏi xác nhận thông minh**: Khi bạn bước vào Vùng Đất Mới hoặc phát hiện Câu Đố Mới, Ni-Oh chủ động lên tiếng hỏi bạn có cần hỗ trợ không.
  - Nếu bạn bảo *"Không cần"* -> Ni-Oh dừng ghi log chi tiết, giữ im lặng tuyệt đối.
  - Nếu bạn bảo *"Cần"* -> Khởi động chế độ ghi log chiến thuật chi tiết.
- Khi được hỏi: Đối chiếu giữa log cục bộ và cẩm nang chiến thuật để trả lời ngay trong 1-2 câu!

### 4. 📁 Đọc & Tạo Mọi Thể Loại Tệp Chuyên Nghiệp
- **Tạo tệp**: Bảng tính Excel có công thức, Tài liệu Word, Slide thuyết trình PowerPoint (`.pptx`), Tài liệu PDF nhúng font tiếng Việt có dấu, Tệp âm thanh giọng đọc tiếng Việt (`.mp3` qua EdgeTTS), Tệp nén ZIP.
- **Đọc chuyên biệt**: Bóc tách ảnh xem trước và thông số từ các tệp kỹ thuật độc quyền như CorelDRAW (`.cdr`), SketchUp (`.skp`), 3ds Max (`.max`), AutoCAD (`.dwg`, `.dxf`), Photoshop (`.psd`), Illustrator (`.ai`).

### 5. 🔌 Cổng Suy Luận Cắm Rút Đa Nền Tảng (Deep Reasoning Gateway)
- Hỗ trợ đổi não bộ suy luận tức thì: **Antigravity (Gemini)**, **OpenAI (GPT-4o)**, **Claude (Sonnet 3.5)**, hoặc **100% Offline trên Ollama**.
- Có thể chạy độc lập như một Standalone App hoặc tích hợp dưới các Hub Quản Lý (Google Antigravity, Claude Desktop, Cursor, ChatGPT).

## 🚀 Hướng Dẫn Khởi Động 1-Click (Dành Cho Mọi Người)

Không cần cài đặt hay cấu hình dòng lệnh phức tạp!

```cmd
# 1. Clone repo về máy
git clone https://github.com/Neito112/Neito-Agent.git
cd Neito-Agent

# 2. Nhấp đúp vào file start.bat để chạy!
start.bat
```

> 💡 **File `start.bat` sẽ tự động**:
> 1. Nhận diện và cấu hình môi trường Node.js.
> 2. Tự động cài đặt dependencies (`npm install`).
> 3. Tự phát hiện GPU & Ollama để kích hoạt chế độ 0-Token Edge AI.
> 4. Khởi động Ni-Oh sẵn sàng phục vụ bạn ngay lập tức!
