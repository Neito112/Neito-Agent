### Fine-tune và nguồn dữ liệu

Dashboard có workspace Fine-tune để tìm và chọn dataset theo protocol từ Roboflow, Kaggle, GitHub và Hugging Face. Key/token được cấu hình local qua biến môi trường:

```cmd
set ROBOFLOW_API_KEY=...
set KAGGLE_USERNAME=...
set KAGGLE_KEY=...
set GITHUB_TOKEN=...
set HF_TOKEN=...
```

Tính năng này hiện quản lý việc **tìm kiếm và chọn dataset**. Huấn luyện YOLO11n vẫn cần bước xác nhận rõ ràng, kiểm tra format/giấy phép và lệnh train riêng; hệ thống không tự tải hoặc huấn luyện mù quáng để tránh dùng nhầm dataset hoặc tốn tài nguyên.
